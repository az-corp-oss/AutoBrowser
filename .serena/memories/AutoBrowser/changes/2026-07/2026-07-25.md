# Changes 2026-07-25

## Rule Sequence Order Persistence Fix
- Fixed a bug where reordering a rule in the list (using the Move Up/Move Down commands) did not update the `Sequence` property of that rule, causing the custom ordering to be lost upon restarting the application.
- Added a helper `UpdateGroupSequences(RuleGroup group)` in `HomeViewModel.cs` to update the `Sequence` properties of all rules in a group sequentially from 1 to `group.Rules.Count`.
- Integrated sequence updating logic into `MoveRule`, `AddRule`, and `DeleteRule` actions of `HomeViewModel`.
- Added / updated unit test assertions in `HomeViewModelRuleTests.cs` to ensure rule sequences are updated correctly after Move Up and Move Down commands.

## Test Timeout Safeguard
- Added `AutoBrowser.Tests.runsettings` file at the workspace root directory with a `TestCaseTimeout` of 30,000 ms (30s) and a `TestSessionTimeout` of 90,000 ms (90s) to prevent tests (especially UI automation tests) from waiting forever.
- Updated `AGENTS.md`, `suggested_commands.md`, `task_completion.md`, and the `AutoBrowser/ui-behavior` memory topic to use `--settings AutoBrowser.Tests.runsettings` when running tests.

## Char-based StartsWith Optimization
- Replaced `.StartsWith("\"")` with equivalent `.StartsWith('"')` for single-character starts-with checks in `BrowserDefinition.cs` and `DefaultBrowserService.cs` to avoid allocating string objects.

## Unused Using Directive Enforcement
- Added `<EnforceCodeStyleInBuild>true</EnforceCodeStyleInBuild>` to `AutoBrowser.csproj` so IDE0005 (unnecessary usings) is caught during build.
- Added convention to `AGENTS.md` and `conventions.md` memory: always remove unnecessary `using` directives after any code change. Use `dotnet format --diagnostics IDE0005` to auto-fix.
