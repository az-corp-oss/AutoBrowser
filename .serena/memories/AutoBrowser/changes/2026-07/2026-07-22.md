# Changes 2026-07-22

## TreeView Replacement with Flat ItemsControl
- Replaced the nested `TreeView` control in `RulesListView.xaml` with nested `ItemsControl`s.
- This changes the UI layout to a flat card structure, resolving issues with inconsistent widths.
- Groups now display as full-width headers and rules sit inside indented blocks under each group.
- Visual selection styling is maintained on both groups and rules by implementing `EqualityToBooleanConverter` in code-behind.
- Visual state changes check equality between current item and `HomeViewModel.SelectedItem`.
- Click-to-select handlers `GroupBorder_MouseLeftButtonDown` and `RuleBorder_MouseLeftButtonDown` updated in code-behind to support the new flat layout.
